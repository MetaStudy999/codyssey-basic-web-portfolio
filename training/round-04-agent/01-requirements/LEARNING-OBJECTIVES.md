## 용어 표기·개념 설명 규칙

- **첫 등장:** 한글명(English Full Name, 통용 약어) 형식. 예: **문서 객체 모델(Document Object Model, DOM)**, **응용 프로그램 프로그래밍 인터페이스(Application Programming Interface, API)**, **계단식 스타일 시트(Cascading Style Sheets, CSS)**.
- **약어가 없는 용어:** 상태(State), 사건(Event), 함수(Function)에 인위적 약어를 만들지 않음.
- **학습한 개념마다:** (1) 뜻·역할 (2) 일상 비유·한계 (3) 그림·코드 예상 흐름 (4) 흔한 오해 (5) 자신만의 설명 (6) 기초 확인 질문을 제공.
