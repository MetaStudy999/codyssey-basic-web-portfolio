### 이 문서에서 자주 쓰는 기술 용어

| 용어 | 처음 보는 학습자를 위한 설명 |
|---|---|
| CORE / BONUS | **핵심 필수 기능 / 선택 추가 기능**. 정확한 공식 구분은 01단계에서 대조합니다. |
| DOM (Document Object Model) | 브라우저가 웹페이지의 요소를 구조화한 것으로 JavaScript가 글자·버튼 등을 바꿀 때 사용합니다. |
| API (Application Programming Interface) | 다른 프로그램에 기능이나 데이터를 요청하는 정해진 통로입니다. |
| Runtime(런타임) | 코드를 실제로 실행했을 때의 환경과 동작 상태입니다. 아직 신규 실행은 하지 않았습니다. |
| SHA | GitHub 커밋이나 파일을 식별하여 어떤 버전을 확인했는지 구별하는 값입니다. |
| PRIMM | 코드를 예측(Predict) → 실행(Run) → 살펴보기(Investigate) → 수정(Modify) → 만들기(Make)로 배우는 순서입니다. |
| Gate | 평가와 다음 단계 진행을 위한 통과 조건이며, 계획된 조건과 실제 PASS는 구분합니다. |

더 쉬운 설명은 [00단계 시작 안내의 용어 풀이](README.md)에서 확인할 수 있습니다.

## 1. 고정 원칙

1. 공식 제2기 Mission PDF 및 공식 `responsive_web_javascript.md` 평가표가 우선합니다. 과거 B4-1 이름이나 Round 01~03 내부 문서는 공식 기준을 대체할 수 없습니다.
2. 기존 Round 01~03 및 `legacy/` 원본·브랜치·PASS·검증·배포 증빙은 유지합니다. 새 Round 04에 기존 소스/증빙을 복사해 신규 성과로 주장하지 않습니다.
3. 신규 미션 코드의 유일한 작성 장소는 `04-src/`입니다. 루트 `index.html`은 **현재 상태 안내용**이며 기존 Round 03 웹은 별도 주소로 보존합니다.
4. **한 번에 한 단계:** 완료 기준과 증빙을 확인해 기록하고 그 다음 단계로 갑니다. 기존에 검증된 환경은 불필요하게 다시 구축하지 않습니다.
5. 사용자 승인 없이 04단계 소스 구현·신규 명령 실행·운영 배포·브랜치 병합을 하지 않습니다. AWS·Discord·iMac 작업은 제외합니다. 공식 미션 필수 AWS 항목은 B1-1에는 해당되지 않습니다.
6. 판단은 `PASS`(증빙 충족), `FAIL`(실제 불충족), `NOT_VERIFIED`(아직 확인하지 않음)으로 나눕니다. 미션 `CLEAR`는 모든 필수 게이트가 충족된 경우에만 판정합니다.

## 2. 공식 범위 개요 — 01단계 상세 추적 예정

### 필수 CORE — 꼭 해야 할 핵심 기능 (공식 요구사항은 01단계에서 항목별 재검증)

- 외부 UI 프레임워크 없이 **HTML / CSS / JavaScript**로 구현; `index.html`, `css/`, `js/`, `images/` 역할 분리
- 시맨틱 HTML, Hero / About / Skills / Projects / Contact / Footer, 앵커, 이미지 alt 및 폼 label
- Mobile First(모바일 우선), 768px / 1024px, CSS 변수, Flexbox와 Grid, 다크 모드 CSS 변수, hover/transition
- 모바일 메뉴, 부드러운 이동, 맨 위 버튼, 스크롤 상단 디자인 변화, IntersectionObserver 애니메이션
- `querySelector`, `querySelectorAll`, `addEventListener`, `classList`, `preventDefault`, `const/let`와 ES6+ 기초 문법
- `localStorage` 테마 유지, 문의 폼 필수값·이메일 오류·상태 표시
- GitHub 공개 API `fetch/async/await/try/catch`와 성공·로딩·오류·빈 결과·HTTP 403·재시도
- 최소 3개의 '사용자 이벤트 → 상태 → 화면 갱신' 흐름
- GitHub Pages 공개 동작, README, 데스크톱/모바일/다크모드 캡처
- 공식 15개 평가 질문에 대한 실제 코드·실행 근거 및 본인 설명

### 선택 BONUS — 여유가 있을 때 더할 수 있는 기능 (CORE 통과 필수조건 아님)

프로젝트 언어별 필터 · 타이핑 효과 · Formspree/EmailJS 실제 전송 · 시스템 테마 자동 감지. 선택 구현 여부는 공식 필수항목 완료에 영향을 주지 않습니다. 실제 전송은 외부 계정/엔드포인트 승인과 개인정보 보호 확인이 선행되어야 합니다.
