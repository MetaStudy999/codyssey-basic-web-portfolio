## 3. 학습 경험 설계

- 쉬운 비유/4컷 만화 → 기술 구조도 → **실제 신규 코드** → **실제 실행·검증**을 연결합니다.
- 각 핵심 용어에는 한글·영어·약어·한 줄 정의·실제 적용·학습 확인 질문을 제공합니다.
- L1 코드 보며 설명 / L2 그림만 보고 설명 / L3 자료 없이 설명 / L4 빈 환경 재현 / L5 새 문제 적용.
- 미션 기능 PASS와 학습 MASTER를 분리하고 증빙 없는 결과는 NOT_VERIFIED로 기록합니다.
- AI 설명 이미지와 실제 스크린샷/로그/코드/공식 수치가 섞이지 않도록 `AI-VISUAL`, `CODE`, `RUNTIME`, `EVIDENCE`, `OFFICIAL`을 구분합니다.

## 4. 제작·검증 순서

- **00~01:** 계획 승인/공식 요구·평가 목표 연결.
- **02~03:** 과거 자료 참고(복제 금지), 학습 목차·개념·구조도·스토리보드 작성.
- **04:** 별도 승인 후 신규 구현과 실제 코드 위치 수집.
- **05~07:** 신규 테스트·실행·근거·평가 답변 확보.
- **08:** 4종 PPTX 및 PDF 실제 제작, 증빙 치환, 전체 슬라이드 가독성/접근성 검사.
- **09:** 버전 SHA, 발표 대본, 평가 연결, 원본·완성 파일 인계.

## 5. 산출물 PASS 기준

각 4종의 실제 PPTX/PDF 파일이 존재하고 장수·구성·공식 평가와 근거가 일치하며, 코드·수치·캡처·검증 결과가 참조 SHA로 역추적될 것. 슬라이드 전체 화면 가독성, 접근성, PDF와 PPTX 일치, L1~L5 학습 질문의 자료 존재가 확인될 것. **계획·빈 폴더만으로 제작 완료나 MASTER를 선언하지 않습니다.**
