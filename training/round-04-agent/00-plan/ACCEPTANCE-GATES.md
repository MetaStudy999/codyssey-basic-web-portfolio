## 실행 승인

- **00~03**: 미션 계획·요구·기존 자료 비교·신규 설계 문서 작업. 사용자의 '단계별로 하나씩'에 따라 매 단계 실제 작업 후 보고.
- **04**: 신규 코드 작성·명령 실행 전 사용자 **명시적 개발 승인 필수**. 지금까지의 경로 생성 및 문서 작성은 이 승인을 의미하지 않음.
- **05~06**: 기존 기능 테스트를 새 Round 결과로 오인하지 않으며, 새 코드의 실제 실행과 필요 시 공개 배포는 실행 범위·승인 및 권한 확인 후 실시.
- **07~09**: 실제 사용자 설명이 필요한 평가 문항을 임의로 PASS 처리하지 않음. 프로덕션 전환·브랜치 병합·운영 변경은 승인 필요.

## 전역 보호

- WSL2 Codex, GitHub 기존 브랜치, Round 01~03 증빙, Pages 이전 URL 및 기능 보존.
- 현재 루트 `index.html`은 **안내 페이지**. 새 미션 산출물 `04-src/index.html`과 혼동 금지.
- 과거 `FINAL_CLEAR` 증거를 변경하지 않음.
- 토큰·비밀키·개인정보 원문을 코드·로그·증빙에 저장하지 않음.
- 실행 불가 및 비검증은 `NOT_VERIFIED`로 보고; 추정 PASS/CLEAR 선언 금지.

## 4종 자료 제작·숙달 별도 게이트 (2026-10-26 승인)

- `01-main-presentation/`: 공식 평가·실제 검증이 출처와 함께 발표되고 발표자 노트와 내용이 일치.
- `02-learning-deck/`: 학습 45장에 쉬운 개념·4컷 만화·실제 구조/코드/실행·실습·자기 설명을 포함. L1~L5 학습 숙달은 **실제 평가되기 전 NOT_VERIFIED**.
- `03-technical-appendix/`: 실제 코드·함수·오류·시험·기술 선택의 근거 및 평가 질문.
- `04-quick-review/`: 핵심 용어·전체 흐름·대표 코드·증빙·짧은 구술 설명.
- 실제 자료와 AI 생성 개념 그림을 구분하며, PPTX/PDF 가독성·접근성·실증 무결성·코드 SHA를 확인.
- **계획과 디렉터리 생성은 PASS(계획)일 수 있어도 슬라이드 제작 PASS는 아닙니다.**
