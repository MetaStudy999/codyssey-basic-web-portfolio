## 목표

용어·개념 정확히 설명→코드 동작 예측→실행·추적→수정→AI 없이 구현·디버깅→새 문제에 응용. 미션 기능 PASS/교육자료 품질 PASS/학습 숙달 MASTER를 **별도 판정**한다.

## 교수학습 16가지

M01 Flashcard · M02 Concept Map · M03 비유/4컷 만화 · M04 Why 질문 · M05 기술 비교 · M06 실행 예측 · M07 코드 추적 · M08 Parsons Problem · M09 빈칸 채우기 · M10 Modify · M11 Debugging · M12 백지 구현 · M13 자기 설명 · M14 전이 · M15 간격 복습/혼합 연습 · M16 AI 튜터/오답 처방.

학습 목표마다 필요한 기법을 골라 적용하며 모두 강제하지 않는다. 핵심 용어는 한글명(English Full Name, 약어), 정의, 필요성, 개념 관계, 실제 적용, 확인 질문으로 구성. 어려운 개념은 비유·4컷 만화→기술 구조도→실제 신규 코드→실제 실행·검증 순으로 연결한다.

## PRIMM 코드 학습

**Predict → Run → Investigate → Modify → Make** 순서로 예측·실행·추적·수정·백지 구현. 학습자가 어려울 경우 H1 질문→H2 개념→H3 절차→H4 예제 해설 수준으로 보조하며, 독립 평가에서는 도움 수준을 명시한다.

## L1~L5 / 복습

L1 코드 보며 설명 / L2 구조도만 설명 / L3 자료 없이 설명 / L4 빈 환경 재현 / L5 새로운 문제 적용. 초기 복습 예시: 직후, 1일, 3일, 7일, 14일, 30일 — 실제 오답 및 기억 유지에 따라 간격 조정. 사전·사후는 동일 역량을 평가하는 동등 난도 문제로 구성한다.
