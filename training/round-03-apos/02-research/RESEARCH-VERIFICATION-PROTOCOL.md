# 연구 미션 근거·재현성 프로토콜

연구는 논문 개수를 세는 작업이 아니다. 실제 주장과 원본 근거를 연결해야 한다.

1. 연구 질문/범위/배제 기준을 먼저 확정
2. 자료 검색: 검색 날짜, 검색어, 데이터베이스, DOI/공식 URL 기록
3. 출처 확인: 저자·연도·버전·원문 접근 여부·철회 여부 확인
4. 주장 연결: 각 주장에 지지·상충·반례 자료와 신뢰도 명시
5. 연구 설계: 변수, 대조군, 편향, 사전 정의된 분석 방법 기록
6. 분석 재현: 데이터 출처·라이선스·처리 코드·환경·결과 대조
7. 독립 QA: 자료와 수치·참고문헌 정합성 및 근거 없는 단정 확인
8. 학습자 설명: 연구 이유·한계·다른 가능한 결론을 자신의 말로 설명

**금지:** 생성한 인용·DOI, 접근하지 않은 논문의 결과 주장, 미확인 실험값을 PASS로 기입. 연구 실험 자체는 P06 NOT_RUN이다.
