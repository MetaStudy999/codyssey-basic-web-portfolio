# 범용 미션 도메인 어댑터 (설계 후보)

B1-1의 웹 구현 방식은 범용 시스템의 **WEB_STATIC 어댑터 예**일 뿐이다.

| 공통 인터페이스 | 설명 | 도메인별 차이 |
| --- | --- | --- |
| Mission brief | 목표·성공조건·산출물 | 개발, 연구, 교육, 창업 |
| Risk profile | 실행 허용 범위와 승인 | 외부배포·자금·개인정보·물리장치 |
| Execution plan | 최소 단계, 의존관계, 중단 조건 | 브라우저, Python, 실험실, 문서 |
| Verifier | 검증 스크립트/평가기준 | 코드 테스트, 통계, 문헌검토, 실제 시연 |
| Evidence index | 출처·버전·무결성·시점 | 실행 로그, 원시 데이터, 인용, 사진 |
| Learning path | 이해→설명→직접 재현→전이 | 주제별 전문용어/실습 |
| Performance record | 품질·속도·비용·실패·독립성 | 동일 입력/조건 비교 가능 지표 |
| Handoff | 안전 재개 지점·다음 행동 | 로컬 기기, 클라우드, GitHub |

## 순서
Core 공통 프로토콜은 `agentic-project-os`에서 관리하고 미션별 어댑터는 필요한 기능만 로드한다. 웹의 `HTTP 200`처럼 도메인 특유의 검사 결과를 연구나 건강 미션의 PASS로 재사용하지 않는다.

**상태:** 제안 및 B1-1 설명 단계. 다른 도메인 검증 전에는 검증된 범용 제품으로 표시하지 않는다.
