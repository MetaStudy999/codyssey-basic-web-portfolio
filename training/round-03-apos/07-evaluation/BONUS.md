# CORE / BONUS / 학습의 별도 판정

## 판정
- CORE: `mission.yml` / `LEARNING-GATE.md`에 따라 CLEAR
- BONUS 1~4: 현재 Round 03 구현·런타임으로 입증되지 않았으므로 NOT_VERIFIED
- 발표자료: 공식 CORE 필수와 별개, 제작·검토 예정
- 사람의 독립 재현·전이: 아직 NOT_MEASURED

## 공식 BONUS
| ID | 기능 | 현재 04-src | 다음 결정 |
| --- | --- | --- | --- |
| BONUS-01 | 언어별 프로젝트 필터 | 언어를 표시하지만 사용자 필터 UI 없음 | 신규 구현·검증 여부 별도 결정 |
| BONUS-02 | Hero 타이핑 효과 | 구현 증거 없음 | 접근성/모션 감소 고려 |
| BONUS-03 | Formspree/EmailJS 실제 전송 | 학습용 검증 UI만 존재 | 개인정보/외부 전송 승인 선행 |
| BONUS-04 | 시스템 다크 모드 감지 | light/dark 수동 테마 존재 | `prefers-color-scheme` 별도 구현·검증 |

## 평가 확장
정답 암기 점수보다 요구 근거 → 코드 위치 → 실제 실행 → 오류 설명 → 변형 문제 해결을 평가한다. 한 번의 구술 설명을 L4/L5 숙달로 과장하지 않는다.
